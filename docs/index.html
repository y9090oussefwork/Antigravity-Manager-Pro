How to switch an Antigravity IDE account

Use the account you choose in Antigravity IDE or Classic. Save open work first, since a desktop switch can restart the client.

  1. Download the Windows x64 installer from the latest GitHub release and open Manager.
  2. In Accounts, add a Google account through browser authorization or review the accounts available to import from your computer.
  3. Find the account, choose Use, then pick Antigravity IDE or Classic. Confirm the account in the Antigravity client after switching.

Compare quota windows

Review five-hour and weekly model quotas where available before choosing an account. Quotas come from the upstream service.

Separate project workspaces

Assign an account to an isolated Antigravity workspace so each project can open with its own client profile.

Connect coding tools

Use the optional local API gateway with supported tools such as Codex, Claude Code and OpenCode.
